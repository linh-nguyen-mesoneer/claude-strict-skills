# Feature Tasks (planning-strict)

Task rules for a feature task: one that adds or changes observable behavior. Read with `plan-core.md`.

**Steps:** write failing test (full code) → run, expect FAIL with reason → minimal implementation (full code) → run, expect PASS → commit checkpoint.

**From a bug:** when `bugfix-strict` handed this plan over, Task 1's failing test is its captured reproduction, failing for the reported reason.
